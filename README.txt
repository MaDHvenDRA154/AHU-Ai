
SETUP INSTRUCTIONS

========================
BACKEND
========================

1. Open terminal in backend folder

2. Install dependencies:
pip install -r requirements.txt

3. Put the Excel file inside backend folder

4. Start backend:
uvicorn main:app --reload

Backend runs on:
http://localhost:8000

========================
FRONTEND
========================

1. Open terminal in frontend folder

2. Install dependencies:
npm install

3. Start frontend:
npm run dev

Frontend runs on:
http://localhost:5173
